# Spring Boot Practice

This repository contains my personal workspace for learning **Spring Boot**. 

## Technologies Used
- **Java JDK 25**
- **Spring Boot 4.1.1**
- **Maven** (using Maven Wrapper `mvnw` for isolated builds)

## How to Run
Every project uses the Maven Wrapper. To run any of the projects, navigate to its directory and execute:
```bash
cd <project-folder>
./mvnw spring-boot:run   # Linux/macOS
.\mvnw spring-boot:run   # Windows
```
